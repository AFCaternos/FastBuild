# 🏗️ FastBuild v1.4

**Minecraft PE 服务器高级建筑保存与导入工具**

> 专为 Minecraft PE (0.14.3 - 1.1.5+) 设计的现代化辅助脚本。凭借全新的多线程支持与流式读写技术，轻松应对百万级方块超大建筑的导出与导入。

---

## ✨ 核心特性

* 🚀 **极速处理性能**：原生支持 **多线程扫描**，大幅提升区块与坐标导出速度。
* 💾 **独家流式读写 (Stream IO)**：专为超大型建筑（百万方块级）打造，边读边写，彻底告别内存溢出 (OOM) 与游戏崩溃。
* 🎨 **现代化图形界面 (UI)**：告别繁琐的纯指令操作，内置精美的卡片式 UI、实时进度条及全套交互菜单。
* 📍 **灵活的导入模式**：支持按 **原始坐标**、**玩家中心** 或 **自定义坐标** 精准放置建筑。
* 📁 **内置文件管理器**：无需切出游戏，在 UI 即可浏览、检索容量及删除已保存的 `.fb` 建筑文件。
* ⚙️ **高度可定制**：通过内置设置面板，可实时调节每 Tick 导出/导入方块数，适配不同性能的设备。

---

## 🛠️ 快捷指令大全

您可以通过聊天栏输入以下指令快速操作，所有指令均支持 `.fb` 或 `。fb` 前缀：

| 指令语法 | 简写/别名 | 功能说明 |
| --- | --- | --- |
| `.fb` | `。fb` | **打开 FastBuild 主控制面板 (UI)** |
| `.fb pos1` | `p1`, `1` | 将当前脚下位置设为 **坐标点 1** |
| `.fb pos2` | `p2`, `2` | 将当前脚下位置设为 **坐标点 2** |
| `.fb cancel` | `c` | 紧急停止/取消当前正在进行的导出或导入任务 |
| `.fb help` | `h`, `?` | 在聊天栏查看快捷指令帮助 |

## 🎮 图形化菜单指南

输入 `.fb` 打开主菜单后，您将看到以下功能模块：

### 📦 区块导出

* 以玩家当前位置为中心，向外辐射导出区块。
* 支持自定义区块半径 (1-16)。
* 支持自定义 Y 轴垂直范围 (0-255)。
* 可选是否包含空气方块。

### 📐 坐标导出

* 利用选定的 **P1** 和 **P2** 坐标划定对角线区域进行精确导出。
* UI 内置“📍使用当前位置”按钮，无需手打坐标。

### 📥 导入建筑

* 提供可视化文件选择器，一键选中目标建筑。
* 提供三种放置策略：原坐标复原、以玩家当前位置为中心铺设、指定 X/Y/Z 坐标点铺设。

## 📁 文件与存储说明

FastBuild 拥有自己专属的文件格式，保障数据的完整与高效读取。

* **文件扩展名**：`.fb` (基于定制的 FBUILD1 + JSON 结构)
* **默认存储路径**：`/sdcard/games/com.mojang/fastbuild/`
* **数据包含**：方块 ID、附加值 (Data)、相对坐标、世界原点、区块尺寸与时间戳。

---

## ⚙️ 高阶设置 (Settings)

针对不同配置的手机或服务器，您可以在 **⚙️ 设置** 菜单中调整以下参数以获得最佳体验：

* **⚡ 多线程加速**：默认开启。利用后台线程预解析方块，大幅减少主线程卡顿。
* **💾 流式读写**：默认关闭。**强烈建议在导出/导入超大建筑时开启**。
* **导出速度**：`1000 - 50000` 方块/Tick（默认 8000）。
* **导入速度**：`500 - 10000` 方块/Tick（默认 3000）。
* **流式导入批量**：`1000 - 20000` 方块/Tick（默认 5000）。

---

> **💡 开发者温馨提示**：
> 在执行大范围（如半径 10 以上的区块）导出时，建议不要随意走动并保持耐心。若遇到卡顿，可尝试在设置中调低“每 Tick 处理方块数”。
